# MultFlow — Downloads

Esta página reúne os instaladores do **MultFlow**, painel gerencial de vendas, financeiro e DRE para Windows.

## Qual arquivo baixar?

| Situação | Arquivo |
|---|---|
| Primeira instalação | `InstaladorMultFlow.exe` |
| Já tenho o MultFlow instalado e quero atualizar | `AtualizadorMultFlow.exe` |

Baixe sempre da **[última versão](../../releases/latest)**. Versões anteriores ficam em [Releases](../../releases).

## Instalação

1. Baixe o `InstaladorMultFlow.exe` na última versão.
2. Execute o arquivo e siga o assistente.
3. Escolha o modo de instalação:
   - **Servidor**: instala o sistema completo na máquina.
   - **Estação**: cria apenas o atalho para acessar o sistema de outra máquina pelo navegador.
4. O diretório padrão de instalação é `C:\MULT\MULTFLOW`.

## Atualização

1. Baixe o `AtualizadorMultFlow.exe` na última versão.
2. Execute e aponte para a pasta onde o MultFlow está instalado.
3. Suas configurações e dados locais são preservados.

## Observações

- O Windows pode exibir o aviso do SmartScreen por se tratar de um instalador sem assinatura digital. Clique em **Mais informações › Executar assim mesmo**.
- Este repositório contém somente os instaladores publicados. O código-fonte não é distribuído aqui.
- Suporte: procure o time responsável pela sua implantação.
